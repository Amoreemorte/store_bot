# Technical specification

Everything is divided into 2 bots - the client bot and the moderator bot. 
## Client bot:
1) The selection function - random ads from random collections
2) The selection function from collections -> selection of collections -> selection from the received products
3) Each product has an option to add it to the cart, and the cart can be viewed, edited, or placed in an order. The cart also displays the cost.

## Moderator bot
1) Only admin ou have access, at least initially
2) Functions: add a selection, add an order. Adding an order is: select a selection -> select a name -> descriptions -> prices -> photos.
3) Orders. For each order, you can receive a link to this bot or simply visit the orders yourself, or both.
